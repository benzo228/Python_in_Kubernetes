# Исключения по безопасности

Уязвимости, которое CI `sca` (`pip-audit`, см. `.gitlab-ci.yml`) игнорирует с помощью параметра `--ignore-vuln`
поскольку **фиксированной версии не существует**. Для каждого идентификатора в файле CI должна быть соответствующая строка, а в каждой строке должны быть указаны владелец и дата истечения срока действия.

## Политика
- Исключение допускается только в том случае, если исправленная версия недоступна. Если такая версия появляется, обновите ее и удалите исключение.
- Срок действия каждого исключения истекает не позднее чем через 90 дней. По истечении срока действия владелец повторно проверяет наличие исправления, после чего либо удаляет исключение, либо обновляет его, указывая новую дату и письменное обоснование.
- Для добавления или обновления исключения необходимо создать мерж-реквест, который обновит как этот файл, так и `.gitlab-ci.yml`.
